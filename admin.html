Conversations

Signed webhook events populate the inbox. Manual sync checks the latest 10 posts and 20 message threads.

Direct messages must be answered within the supported window. Attachments, unsolicited outreach and older conversations should be handled in Instagram.

Automation controls

Pause stops new outbound actions. An API call already in progress may complete.

What automatic replies can say

Only exact, short questions about what UNIO is, how to register interest, and whether services are operating receive fixed, approved answers in English or Spanish. Replies link to official UNIO information.

Other questions go to review. Financial promises, complaints, personal-data requests and commitments are not answered automatically. Incoming text cannot change these rules.

Automatic queueing selects content from your approved reusable library, at most once per account per UTC day. Each library entry has a 30-day cooldown. Starting copy uses fixed templates; this version does not generate new AI artwork or captions autonomously.

Uncertain publishing or reply outcomes are marked for review and are not blindly retried. Check Instagram before taking another action.

One-time Meta setup

Connect directly to Instagram.

Meta app not configured.

  1. Open Meta for Developers, create a business app and add Instagram API with Instagram Login. Use a professional Business or Creator Instagram account.
  2. Use the Instagram App ID and Instagram App Secret shown in that product’s setup. Add the OAuth redirect URL below exactly. Use the Graph API version displayed in your app dashboard.
  3. Choose a long random webhook verification token. Save it with the app settings below before validating the webhook in Meta. Then configure the webhook callback URL and subscribe to comments and messages.
  4. Request the permissions instagram_business_basic, instagram_business_content_publish, instagram_business_manage_comments and instagram_business_manage_messages. Complete account testing, app review or business verification when Meta requires it.
  5. Set the app privacy URL to https://unio.today/privacy.html. Before production approval, ensure it covers Instagram administration, message retention and deletion. Use the deletion instructions at https://unio.today/privacy.html#instagram; add any callback Meta requires for your app configuration.
  6. Save the settings below, then connect each UNIO Instagram account. Confirm webhook subscriptions in Meta. Test delivery and permissions before enabling automation.
